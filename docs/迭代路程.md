# ΜΝΗΜΗ 迭代路程（v0 → v8.8）

这份说明写的是**网站引擎**怎么长成现在的样子，不是传记正文的写作史。  
公开 Git 历史从引擎抽离提交开始；更早的版本活在本机与私有部署里。下面按产品事实排列，不编造精确日期。

线上实例（口令进入）：https://mneme-biography.app.workbuddy.link/  
引擎仓库：https://github.com/LYL-Z/mneme-web（MIT）  
知识库本体：[LYL-Z/the-memory](https://github.com/LYL-Z/the-memory)（私有，不含在本许可证里）

---

## 产品是什么

ΜΝΗΜΗ 不是博客主题，也不是通用笔记发布器。它是一台**编辑向传记装置**：

- 纸色 / 青铜 / 爱琴海 palettes，正文永远是实心纸面。
- 液态玻璃与沉浸光感只落在**系统铬**（顶栏、侧栏、底栏、弹窗），不铺到段落上。
- 网站只记录本机现场（划线、足迹、丝带、偏好），**不写回** Obsidian 库。
- 知识库改动经 ingest **单向**进入只读库。
- 可见性分三层：公开 / 私密（未解锁等同不存在） / 绝密（目录可见、正文上锁）。

对标对象是博物馆网站、苹果/华为系统铬、编辑部排版，而不是通用 SaaS 仪表盘。不宣称任何数字「世界级分数」。

## v0 · 只有库，没有馆（起源）

起点是 Obsidian 知识库「The Memory」：人物页、班级名录、素材、百万字散文式自传的目录与章稿。阅读发生在编辑器里，关系靠双链，没有对外的门厅。

这一阶段定下后来所有版本都不能破的约束：

1. **事实层优先于文笔。** 人物页、来源状态、隐私规则决定能写什么。
2. **私密层不得混进公开导出。** `私人资料/` 与口令永不进网站引擎仓。
3. **网站若存在，也只能是库的投影**，不能反过来改库。

没有 v0 的站点代码。v0 是装置的伦理，不是仓库里的 tag。

## v1–v3 · 装置成型

第一批站点把库收成可走的空间，而不是一篇长页：

| 空间 | 希腊编号 | 职责 |
| --- | --- | --- |
| 记忆恒星 | Σ1 | 门厅、丰碑、工作台入口 |
| 时间之河 | Σ2 | 年表与巡航 |
| 人物星图 | Σ3 | 实体与共现 |
| 原文档案馆 | — | 三栏阅读 |
| 书房 | — | 《补写的手册》六部 |
| 主题域 / 他者之声 / 意象博物馆 / 证据灯塔 | — | 域、问卷、意象、证据 |

同期落地、后来一直沿用的底座：

- **访问口令门**（`MNEME_TOKEN`）与序章动画（可跳过）。
- **纸 / 墨夜**双主题，跟随系统，可手动覆盖。
- **命令面板**（⌘K）、阅读位置 LRU、丝带续读。
- **工作台优先**：导航把「原文档案馆」放在第一位——正文才是产品。
- 设计令牌收口（`web/src/styles/tokens.css`），避免每个组件自造字阶。

v3.x 的注释还留在代码里（v3.2 门禁跳过与命令面板、v3.4 工作台、v3.5 四分组导航）。它们标记的是装置骨架，不是营销版本号。

## v4 · 星空图书馆（2026-09-09）

见 [v4.0-跨越式升级-执行记录](./v4.0-跨越式升级-执行记录.md)。这一批把「能打开」做成「能读」：

- **三栏档案馆**：左目录树、中正文、右来源检查器，均可收起。
- **阅读器设置**：字号 / 行宽 / 宋黑，写入 `localStorage mneme-reader`。
- **路由代码分割**：九个空间 `React.lazy`，首包从约 137KB gzip 收到 73KB 量级。
- **CSP Report-Only**、登录失败限速、`nosniff` / `no-referrer` / `SAMEORIGIN`。
- 方案里当时未做完的 C 组（PWA、每日星座、拼音检索、键盘层等）在后续版本补齐。

C2「每日星座」的哲学在这一阶段写定：**以日期为种子，星等与连线必须来自真实图谱，不伪造人物。**

## v5–v7 · 沉浸光感、粒子、星图与河

这一段把系统铬做成可感知的材料，同时把两个最重的空间做成可停留的场地。

**沉浸光感（对标华为 ImmersiveMaterial / 苹果 Liquid Glass 的 Web 近似）**

- 通透材质、渐变模糊、按压弹性、按压点光源、材质流光、智能反色。
- 档位：`exquisite` / `gentle` / `smooth` / `adaptive`（按 CPU、内存、系统、壳层挑选）。
- 正文保持 `.surface`，玻璃不进段落。

**粒子湮灭（v5）**

- 弹窗关闭：卡片保持原样 → 底到顶噪声锋面 → DOM 用 `clip-path` 跟着裁 → 快照粒子接管并上浮消亡。
- WebGL2 主路径，Canvas 2D 回退。预采样缓存在弹窗打开后空闲跑，关闭时零等待。

**星图「行星旷野」（v7）**

- 实体按星等以黄金角铺开，力导向只做碰撞松弛。
- 姓名牌屏幕空间绘制；俯瞰只标高星等，放大全显。
- 搜索飞行定位；触屏双指捏合；滚轮以指针为锚（非被动监听，避免整页跟着滚）。

**时间之河**

- 巡航按 16.67ms 标准帧折算，避免 120Hz / ProMotion 上加倍加速。
- 年距、月相、事件卡扇形错位，密年走紧凑档，减少叠卡。

**签名墙**

- 手迹去底（慢变光影走局部估计，纯色底走全局），嵌进门厅，不做成贴纸墙。

**全设备壳**

- `index.html` 在首屏脚本里写入 `data-os` / `data-shell` / `data-pointer`，避免鸿蒙、iOS 先闪桌面左栏再收成底栏。
- `viewport-fit=cover`、安全区、`100dvh`、系统字号不破版。

v7.1–v7.3 的本机验收稿含默认口令与旧生产地址，**已被 `.gitignore` 排除**，不进公开仓。

v8.7 还固定了一条产品规则，后面不能再回退：

1. **致谢公告必须保留。**
2. **背景曲默认开，但只有「口令进入 → 致谢弹出 → 用户关掉致谢」这一次手势之后才出声。**

## 现在还坚持的原则

1. **玻璃在铬上，墨在纸上。** 新增特效不得铺到正文。
2. **私密层不可枚举。** 未解锁与「没有这页」同一张 404。
3. **绝密不是整部上锁。** 六部书房公开；上锁的是指定章节与非父母卷作答全文。
4. **不把推测写进人物页。** 第一人称正文可以推断、可以替想；引擎不因此降低证据出口。
5. **发版后旧哈希必须失败得干脆。** 宁可 404，不可用 SPA 回退假装脚本还在。
6. **开源的是装置，不是生平。** 复现方法公开；库、口令、第三人资料不公开。

下一档优化仍然走编辑向与可达性，而不是再给正文加一层玻璃。
